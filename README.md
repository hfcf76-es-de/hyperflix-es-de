# Hyperflix (https://github.com/hfcf76-es-de), a theme for [ES-DE](https://es-de.org/)


Hyperflix attempts to simulate the look of the [HyperSpin](https://hyperspin-fe.com/) frontend for ES-DE by combining two themes originally created for the [LaunchBox](https://www.launchbox-app.com/) frontend. 

The original themes can be found here:

Unified by CriticalCid: (https://forums.launchbox-app.com/files/file/1080-unified/)

Refried by RetroHumanoid :(https://forums.launchbox-app.com/files/file/1506-unified-refried-20/)


## Configuration Options

- `Theme Aspect Ratios`: 16:9, 16:10, 19.5:10 and 4:3



- `Theme Variants`:

Unified (Wheel):
Backgrounds and frames for videos, featuring a unified style with lists of systems and games displayed in a circular carousel

Unified (Vertical): 
Backgrounds and frames for videos, featuring a unified style with lists of systems and games in a vertical carousel

Unified (Vertical Wheel):
Backgrounds and frames for videos, featuring a unified style with lists of systems and games displayed in a circular carousel, with items arranged vertically

Refried (Wheel):
Backgrounds and frames for videos, featuring a retro-refried style with lists of systems and games displayed in a circular carousel

Refried (Vertical):
Backgrounds and frames for videos, featuring a retro-refried style with lists of systems and games in a vertical carousel

Refried (Vertical Wheel)
Backgrounds and frames for videos, featuring a retro-refried style with lists of systems and games displayed in a circular carousel, with items arranged vertically


- `Theme Color Schemes:`

[Silver] Carousel Logos:
System logos presented within a rounded, silver-style border

[Carbon] Carousel Logos:
System logos presented on a rounded, carbon-style border

[Rect] Carousel Logos:
System logos presented in a rectangular format with a black border

[Clear] Carousel Logos:
Original system logos surrounded by a white border
